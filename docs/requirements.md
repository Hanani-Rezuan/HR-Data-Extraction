# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow Human Resource Administrator to upload or capture Human Resource physical documents.
2. The system shall automatically extract correct employee information from the uploaded physical documents.
3. The system shall identify and map extracted information to the correct fields in the system.
4. The system shall display the extracted data for user verification and correction before saving the data in the system.
5. The system shall store the verified information in the system database and keep the data safe. 

## Non-functional requirements (how the system must PERFORM)
1. The system shall process and diplay extracter information within 11 seconds for standard Human Resources physical documents.
2. The system shall achieve atleast nearly 95% accuracy in extracting Human Resource fields under supported document conditions.
3. The system shall protect employee information by allowing the access only to the authorized users like Human Resource Administrator.
