# User Stories

1. As a Human Resource Administrator, I want employee information to be extracted automatically from Human Resource documents, so that i can reduce manual data entry workload.
   
2. As a Human Resource Administrator, I want to extract information and it mapped into the correct system fields, so that it will lower the chance of data entry errors.

3. As a Human Resource Administrator, I want to review and correct the extracted information before saving so that i can ensure the data accuracy.

4. As an employee, I want my information to be processed accurately and efficiently, so that my Human Resource records can be updated more faster and more consistently.
