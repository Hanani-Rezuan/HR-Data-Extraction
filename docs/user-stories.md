# User Stories


1. As a Human Resource Administrator, I want employee information to be extracted automatically from Human Resource documents, so that i can reduce manual data entry workload.

Acceptance Criteria : 
1. Human Resources documents that can be captured or uploaded. 
2. Information of employees can be extracted automatically. 
3. Mapped extracted data to the correct text fields.
4. Reviewing and editing the extracted data can be done by the Human Resource Administrator. 
5. Data that has been verified can be successfully saved.
   
2. As a Human Resource Administrator, I want to extract information and it mapped into the correct system fields, so that it will lower the chance of data entry errors.

Acceptance Criteria : 
1. Relevant information can be extracted from the documents can be identify by the systems.
2. Extracted value to the prespesified system fields shall be mapped by the system. 
3. The system can show and emphasize the fields that are high probability to be mistaken and uncertain mapping. 
4. Review and correcting each of the information can be done by the Human Resources before save it. 
5. The system are highly avoiding any information to be saved without user validation. 

3. As a Human Resource Administrator, I want to review and correct the extracted information before saving so that i can ensure the data accuracy.

Acceptance Criteria : 
1. The system can shows all the data that has been extracted before saving. 
2. The Human Resource can be able to edit any incorrect values from the extracted data. 
3. The system can show and emphasize the fields that needs verification. 

4. As an employee, I want my information to be processed accurately and efficiently, so that my Human Resource records can be updated more faster and more consistently.

Acceptance Criteria : 
1. Employee information can be process by the system automatically. 
2. The system needs to ensure the information that extract must be reviewed by the Human Resource Administrator before updating the record. 
3. The system shall maintain on consistent data formats of all data.
